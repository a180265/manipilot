# 目标范围内微移点击

2026-10-17；`arm.click 1.1.0` 的向后兼容扩展。

`click_attempt` 是可选整数：0（默认）沿用中心点；本台显式启用下述选点策略时，
在目标安全区域内选择一次落点。1、2选择同一安全区域内的两个替代点。
调用方只提交目标与尝试序号，不提供偏移量或机械坐标。一次能力调用只执行一次点击；
驱动不会因没有页面反馈自行补点。返回 `click_attempt`、`click_retry_supported`，
后者只表示具备有效替代点，不证明点击成功，也不授权下一次点击。

当前适用范围是已验证摄像头文字目标 `conversation_item`，以及共享布局当次通过的
`input_box/back_button`。旧坐标点没有目标范围，不支持微移；发送、删除、输入法候选、
一次性授权目标及悬停动作不能使用非零尝试序号。无效序号、目标过小、误差未知、来源或
绑定变化在运动前拒绝。已有校准有效性、租约、取消、动作预算和接触前复核仍适用。

替代点沿安全区域的长方向小幅移动，最多12个屏幕像素；安全区域扣除映射误差和定位
余量。透视目标按实际边界约束，不把轴对齐包围框的外扩部分当作可点击区域。
OCR凭据保留原位置、来源和 `locationId`，驱动内部选择替代点；调用方不得改坐标伪造凭据。

本台校准档案可选 `xy.clickPointPolicy`，缺省关闭。启用值精确为
`{"mode":"screen_interior","preferredInsetsPx":{"left":0,"top":0,"right":0,"bottom":0}}`。
四项边距均为有限非负的屏幕像素，左右之和须小于屏幕宽度，上下之和须小于屏幕高度。
这里只表达避开手机边缘的选点偏好，不声明整个内部区域可靠，也不改变校准精度门槛。
配置不由 `arm.click` 调用方指定。非法配置拒绝动作，不能当作缺省关闭。

该策略只作用于共享布局当次通过的点击目标和已验证 OCR 文字目标。共享布局使用已扣除
误差的 `safe_rect`；OCR 必须保有原 `locationId` 对应的真实 `cameraPolygon`，投影后按
当前实测误差包络加 2 屏幕像素内缩。原中心安全且位于偏好区时保持；否则取安全目标与
偏好矩形的交集内点。未知误差、缺少真实四角、交集为空或退化时，在运动前拒绝，
不回落到不安全的原中心，不把文字框扩大成联系人整行，不对只有坐标的旧固定点自行偏移。

启用策略后，两个重试候选仍最多各偏移 12 屏幕像素，并始终留在同一交集；第一次
选点到原中心的距离由真实安全范围约束，不冒充 12 像素微移。回执 `click_point` 额外
记录 `originalCenter/aim/selectionOffset/policy`，坐标域为校准屏幕像素，不含识别文本。
主动选点偏移不计作拟合误差。`xy` 整体属于机械校准指纹，策略新增、变化或删除都会
撤销旧机械资格引用；当次布局/文字凭据及共享 screen-proof 绑定也随策略变化失效。
没有策略时保留已有中心与重试兼容行为。

业务插件负责证明效果。仅在两张新鲜、递增且绑定相同的点击后画面明确证明页面与目标
稳定、动作未生效时，才重新定位原目标并调用下一序号。结果未知、画面陈旧、同名歧义、
目标移动或已发生页面变化时停止。每次动作前保存持久意图，崩溃重入不得补发未确认动作。
每个目标最多三次接触；原任务截止时间、动作预算及权限继续约束每次调用。

首次点击没有可用效果证据的旧驱动保留既有单击和上层核验逻辑；新驱动支持微移而证据
不足时报告未知。接触回执只证明机械动作，不能独立证明业务效果。
