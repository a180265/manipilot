# 校准区域命中验收

版本：`calibration-region.v1`，日期：2026-10-17。判据键为
`target_region_v1`（中文：目标安全区域命中）。这是机械校准资格，不能替代每次
任务的目标识别、输入许可、发送批准或操作后的效果核验。

新校准轮冻结判据，正式档案写入 `validation.criterion`。只有缺少该字段的历史
档案沿用原像素误差门槛；未知值（包括空值）拒绝，不得回退历史 `motion_ready`
路径。模型锁、同轮 run、设备/相机绑定、daemon 会话、Z 验证及安全停车位要求不变。

## 单点证据

`calibration_region_evidence(target_rect, screen, actual_touch, camera_point=None)`
是纯函数。屏幕尺寸使用 `screenWidth/screenHeight`；坐标为屏幕像素 `[x,y]`。
标靶为冻结的归一化矩形 `{u,v,widthU,heightV}`，其中 u/v 为中心。所有数值必须
有限且不能是布尔值；尺寸必须正，标靶必须完整位于屏内。宽度不得超过
`2*min(.06,.6*u,.6*(1-u))`，高度按 v 同式计算；不得通过扩大验收靶规避误差。
非法输入抛 `ValueError`，不会产生成功证据。

返回对象：

| 字段 | 中文含义 |
|---|---|
| `criterion` | 固定为 `target_region_v1` |
| `targetRect` | 冻结的归一化标靶矩形 |
| `actualTouch` | 手机实际触点，保留原始精度 |
| `cameraPredictedScreen` | 相机瞄准点在屏幕中的坐标；辅助尺寸计算可为空 |
| `boundsPx` | 原靶像素边界 `{left,top,right,bottom}` |
| `safetyInsetPx` | 原靶像素短边的 5%，不是固定像素数 |
| `safeBoundsPx` | 四边均内缩上述距离后的像素边界 |
| `marginPx` | 实际触点到原靶四边的最小距离；靶外为负 |
| `cameraMarginPx` | 相机瞄准点的同类裕量；无瞄准点时为空 |
| `touchTargetErrorPx` | 实际触点与名义靶中心距离 |
| `cameraTouchGapPx` | 实际触点与相机瞄准点距离；无瞄准点时为空 |
| `passed` | 触点在安全内缩区内；提供相机点时，相机点也须在安全内缩区内 |

正式验证点保存 `u/v`、`regionEvidence` 及外层两项误差。
`calibration_region_point_passed(point, screen)` 从 `point.regionEvidence`
中的原始坐标与冻结靶重新计算，**不信任**保存的 `passed`、边界或裕量摘要。
它要求相机瞄准点存在、与触点都在安全范围，并核对外层 u/v 与靶中心、两项距离
与实际计算一致（兼容原三位小数记录，绝对差不超过 0.00051 px）。
缺失或矛盾证据返回 false，不以“距离中心较近”兜底。

## 正式资格与拟合质量

新判据须有同轮的五个独立点 `validation-1` 至 `validation-5`，各点均按上述规则
重新核验。点外层 `passed` 和总验证结果仍须明确为 true；把失败摘要改为 true
不会跳过实际几何检查。30 px 距中心误差可以通过，前提是实际触点和瞄准点都留在
真实标靶的安全范围内；不存在“统一放宽至 30 px”的全局阈值。

`xy.modelSelection` 保存选中模型及完整留一误差，`xy.samples` 按拟合输入顺序保存
每个样本的 `u/v`、`targetRect`、`actualTouch`、`effectiveRobotXY`。
样本至少 9 个，允许累积重采样，`sampleCount` 和 `residualsPx` 长度必须一致。
选中模型的 `leaveOneOut.maxErrorPx/rmsPx` 从逐点误差重新计算核对；每一项误差
须不大于**对应训练靶**中心到安全内缩边界的最小距离。训练残差须有限非负，
`xy` 与选中模型 `training` 摘要一致。新判据以此替代固定 RMS 3/max 6 px 拟合门；
历史未标记档案保留原门槛。

## 执行误差范围

`mapping_error_bound` 对新档案重新核验五点、训练留一证据及所有视觉复验点。
误差范围至少覆盖逐点实际触点到靶中心距离，以及实际触点到相机瞄准点的最大距离
加相机重投影误差；同时纳入选中模型逐点留一误差的最大值。
缩小汇总摘要不能缩小该范围；非法、失败或矛盾点返回不可用。
实际任务仍须有可信目标范围，按真实误差范围留出安全余量；校准通过不保证任意
小按钮或无边界裸坐标可点击。

错误检查项：`calibration_validation_criterion_unknown` 表示验收判据未知；
`xy_region_quality_invalid` 表示训练残差、留一证据或冻结标靶裕量不完整/不合格；
`motion_qualification_incomplete` 仍表示正式模型锁、验证或安全记录不完整。
以上均不得自动修改档案补资格，应保留失败证据并重新校准。

## 业务落点与输入法范围

共享布局使用已扣除映射误差与定位误差的安全矩形；可信 OCR 使用真实四角，首次点击也必须有可用的内缩区域。新区域档案不允许 OCR 安全区失败后退回中心点，也不允许仅有中心坐标的旧固定目标继承点击资格。

输入法几何目标由已认证的手机快照提供 `bounds={left,top,right,bottom}` 与 display 尺寸。平台保留该范围，驱动在屏幕像素域扣除实测映射误差及数值余量后选择单次落点；范围不足则零点击拒绝。最终接触门核对原始目标引用与已消费快照的范围，变化后禁止按旧范围点击。候选与删除不会因此增加微移重试。

## 常用区域验证计划与最终接触检查

2026-10-17 起，新区域校准默认独立验证位置为 `(0.20,0.10)`、`(0.80,0.10)`、`(0.20,0.90)`、`(0.80,0.90)`、`(0.50,0.65)`。训练仍为 10%/50%/90% 九点，独立点不参与拟合；逐靶尺寸规则及命中判据不变。这是常用区域验收，不代表极限边角或任意小目标通过。旧候选保留其冻结的计划与失败结果。

`arm.click` 在传输锁内用最终 MPos 回投冻结目标安全区；校准变化或越界时不下压。OCR 路径保持原姿态补偿；IME 范围核验通过后才消费一次几何 nonce。该检查不改变独立双击或滑动契约。
