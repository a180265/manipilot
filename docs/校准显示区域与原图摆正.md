# 校准根视图、完整显示屏与原图摆正

2026-10-18 修复，WX 与独立 SDK 已双向实现。现场重新校准、输入与页面业务验收仍分别记录，本文的软件回归不代表真机业务验收完成。

校准靶和 Android 触点使用校准 Activity 根视图坐标；输入法候选等范围使用完整 display 坐标。状态栏可以使 root 原点不为零。例如已保存现场证据为 root 1080×2320、display 1080×2400、origin [0,80]。该例用于诊断，运行时不得硬编码或从旧轮旁档推测 80。

自动校准开始时读取并冻结同设备、同校准 session 的 legacy metadata。需满足原校准页、坐标版本 2、rotation 0、正尺寸、有效客户端及 density、根视图在 display 内。根尺寸须与本轮触点基线一致。提升后：

- `screen.displayGeometryVersion=1` 标记新的坐标语义。缺元数据仍可保存机械资格，但布局登记/运行明确拒绝。
- `screen.calibrationRootEdgeModel` 保存本轮相机独立观察到的校准页根轮廓。
- `screen.displayCoordinateMetadata` 保存本轮原始坐标桥证据。
- `screen.edgeModel` 的 `coordinateDomain=android_display`、`referenceVersion=1`；四角由本轮 H 和 display/root 关系反投影。它是完整显示屏的**参考几何**，不是新的相机观察证据。
- `autoCalibration.phoneSessionId` 与本轮 run 保留；手势坐标桥旁档用最终校准指纹、当前 run 及冻结的元数据生成，页面关闭后无需借用旧旁档。

布局登记和运行必须独立检测当次完整手机四角并通过原有姿态门、来源身份、粗框、图像字节摘要等校验。新显示屏参考必须与元数据及 H 一致，未知版本、缺失证据或改动后的参考一律拒绝。重新校准的找靶过程继续使用原根轮廓。

摆正把相机原图通过 `H × inverse(pose)` 一次采样到校准根视图。先检查连续根视图反投影位于完整显示屏参考内，再检查姿态补偿后的全部采样范围位于真实相机源图及粗框内。取消的是整数化轮廓掩码引入的假边界，不是物理包含校验；不会用 127 填充、复制边界或盲目扩边伪造证据。

离线回归包括：真实数值 H 与 root/display 原点、原始根证据保留、错 session/尺寸/origin/方向拒绝、分数像素边界无假填充、真实越界拒绝、姿态与 H 单次组合、自动开始冻结、页面关闭后旁档保存及新模式缺桥拒绝。保留的两张现场原图只用于内存诊断复放；使用历史 origin 的复放不能提升或修改现场资格。正式验收必须重新获得真实同轮 metadata 并重跑校准。
