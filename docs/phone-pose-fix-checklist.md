# 手机定位、偏移补偿与动作不确定性修复清单

本轮范围：手机屏幕视觉、校准、唤醒、点击、上下滑动、WX 坐标桥和未知动作保护。
临时问题文档在修复及独立复测完成后删除；长期验收状态保留在验收总表。

## 验收约束

- 持续推流先定位绑定手机，再分析屏幕，环境亮度和文字不参与业务判断。
- 屏幕极暗但帧新鲜时等待恢复，不将设备或校准判为离线；唤醒还必须定位手机。
- 可可靠拟合的小幅手机偏移补偿到机械坐标；不得重复补偿实时观察坐标。
- 采样校准中手机移动、定位不稳定、过期/冻结帧或超出补偿范围时停止触屏。
- 未知回执不执行下一动作、自动清理、归位或重放；服务重启必须保留此限制。
- 历史任务保留原结果，但不以已解除的历史问题阻碍新流程。
- 软件测试不能代替当前会话的上下滑动、黑屏唤醒和微信页面实机验收。
