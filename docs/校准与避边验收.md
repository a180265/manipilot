# 九点自动校准与区域内避边验收

适用：2026-10-17 更新后的机械臂调试台。校准页的真实触点回报用于建立和验收映射；业务运行依靠摄像头识别目标、动作后画面确认效果，不要求业务页面上报触点。

## 操作步骤

1. 打开本机调试台 `http://127.0.0.1:8792`，选中实际机械臂和在线输入法设备，手机停留在校准页。设备/相机绑定及手机粗框应为当前配置。
2. 在「统一校准向导」点击「① 开始校准」，等待手机页已打开。开启或修改避边后需要新一轮校准，不能直接恢复没有冻结该策略的历史候选。
3. 按 AUTO 区提示复核悬停高度、点击参数和安全停车位。确认点击参数时，触头应在屏幕内的安全悬停位置；确认停车位时，应已移到屏幕外的停车位置。沿用本台已验证的数值，不把其他设备的参数照抄过来。
4. 点击「启动自动校准」。新一轮默认显示「按目标范围验收」。流程自动完成相机九点识别、中心检查、九点机械采样、九点视觉复验和五点常用区域独立验证。基础接触次数为 24 次，重试另计；不需要手工校准 16 个点。
5. 结果以**本轮编号与当前档案**共同判断：本轮已保存，当前档案为 `motion_ready` 或 `ready`，两处验收模式均为「按目标范围验收」，校准检查无阻断；刷新页面后仍一致。查看样本的区域命中结果与边界余量，需要留档时点击「导出校准报告」。历史列表中的 `PROMOTED` 和设备连接显示「可用」都不能单独证明当前校准通过。
6. 回到实际应用做功能验收：找到指定对象并进入、返回、点击输入框、下发并点击输入法候选文字。发送验证由操作者选择自己的测试会话和测试文本，并核对只出现一条新消息。输入与发送需要页面中的「允许输入与发送」开关及目标适配有效。

已退役的 E 输入验收入口不再是操作步骤，不要尝试通过旧接口改写校准资格。

参数测试的「一次」指一次下压与抬起。等待触点回报时，测试、点动、停车确认等操作会暂时禁用；急停和停止仍可用。即使重复提交请求，服务端也会拒绝且不会排队补点。画面或手机位置检查不会夹带唤醒点击；暗屏时先点亮，再主动重试。

成功后看 AUTO 区的「准备已完成」提示，再点「启动自动校准」。标为「上次」的失败属于历史运行，不代表刚确认的参数失败。

新区域校准的五个独立点为屏幕归一化位置 `(0.20,0.10)`、`(0.80,0.10)`、`(0.20,0.90)`、`(0.80,0.90)`、`(0.50,0.65)`，与九个拟合点不同，仍不参与拟合。此轮以常用控件区域为验收范围；未证明 5%/95% 极限角点或极小边缘控件可用。历史候选保持创建时冻结的验证位置，失败记录不因新默认计划而变为通过。

## 怎么判断命中

实际应用以点击落在真实可点击区域、触发预期效果为验收目标。偏离中心 30 像素不自动等于失败，也不自动等于成功：目标边界和周围其他控件决定是否可接受。

- 联系人：进入的是指定聊天，由新画面核对身份。
- 返回：回到预期主界面。
- 输入法候选：原文完整进入输入框，没有重复插入。
- 发送：出现对应的新消息气泡、输入框清空，结果不明确时不自动重发。

可在上中下位置及靠边控件分别复测，并隔一段时间重复。记录未触发、误点邻近区域和结果未知；单次成功或校准页大靶命中不能代替整个应用验收。

新一轮自动校准采用 **`target_region_v1`：按目标范围验收**。每个真实标靶矩形按自身短边的 5% 向内收缩，实际触点落在收缩后的范围内才通过。例如标靶为 300×100 px，四边各内缩 5 px；这与对整块屏幕取 5% 不同。九点视觉复验和五点独立验证都必须通过，触点身份、设备绑定、姿态及运动安全检查也照常执行。

模型 RMS、距中心偏差和相机触点间隙保留为诊断数据，不再用固定的 3、10 或 30 px 统一判定目标命中。30 px 的偏差如果仍落在该目标安全范围内，可以通过；目标小、越出边界或误中相邻控件则不能通过。缺少真实目标范围或区域证据时，不会仅因中心误差小就算成功。

正式记录中，候选的 `validationCriterion` 与保存档案的 `validation.criterion` 都为 `target_region_v1`；每点的 `regionEvidence` 保留真实范围、安全范围、内缩量、边界余量和命中结果。旧候选或旧档案缺少该模式字段时，继续标为「中心精度验收（旧模式）」，沿用原判据。不能把历史失败直接改成区域通过，也不能手改 `passed`/`ready`；需要启动新一轮获得实测证据。

校准通过证明这些分布在屏幕上的标靶通过了区域验证，不代表任何大小的业务按钮都能点击。实际 WX 控件还需有可信范围，扣除测得的映射误差和定位误差后仍有可点击空间，才允许执行。OCR 文字框不会自动扩大成整行按钮；仅有旧坐标点、范围缺失或小框内缩后为空的目标，需要补充真实控件范围或重新适配，不能套用「允许 30 px」绕过。输入法候选与删除目标使用手机上报的真实控件边界，并需保持几何快照新鲜。

## 避边设置与生效范围

调试台配对信息下显示「区域内避边：已配置」及四侧像素边距。设置保存在本台 `calibration_bundle.json` 的 `xy.clickPointPolicy`，没有配置时保持原选点行为。

```json
{
  "mode": "screen_interior",
  "preferredInsetsPx": {"left": 0, "top": 150, "right": 0, "bottom": 0}
}
```

上述 150 px 是一台 1080×2320 手机的实测配置示例，不是所有手机的默认值。首次点击在真实目标扣除映射误差后的安全区域内，优先选更靠屏幕内部的位置；没有偏好交集时，仍在原安全目标内尽量向屏幕内部选点；真实安全区为空则拒绝点击。文字框不会被扩大成整行按钮，没有真实范围的旧坐标不会自行偏移。

自动开始会冻结策略，采样、恢复和保存时校验一致性；重新校准和会话重绑保存后仍保留设置。策略中途改变会停止该轮，旧截图和定位凭据也不能继续用于点击。

避边与微移重试不同。微移仅在允许的目标类型、已有证据确认未生效后发生；发送、删除和输入法候选不因此增加自动重复点击。
